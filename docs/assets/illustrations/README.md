# Editorial illustration provenance

These three images were generated on August 4, 2026 with the built-in image
generation capability, following the Standard Mode compiler in
[`gc-minimal-zine-poster-v0-1`](https://github.com/LiamGvchi/gc-minimal-zine-poster)
at source commit `4cb0396ad4e834019f753b37e1c4f415f5e02026` (MIT license).

The illustrations provide visual rhythm and conceptual metaphors only. They do
not depict new experiments, numerical results, hidden reasoning states, or
scientific evidence. All scientific claims on the page remain supported by the
paper text, tables, and original figures.

Each selected 971 × 1619 PNG was converted to WebP with ImageMagick at quality
86 and stripped of embedded metadata. There was no crop, retouching, compositing,
or content edit after generation.

## `support-reachability.webp`

- **Page role:** transition from catastrophic forgetting to future effective
  support
- **Recipe:** lower-middle route cluster / old notebook illustration / small
  typewriter phrase / cobalt risograph anchor / xerox grain / quiet archival
  mood
- **Interpretation:** one route remains discoverable while another fades before
  an open gate; this is a sampling-budget metaphor, not capability erasure

Final generation prompt:

```text

small lower-middle hand-drawn cluster, show a forked route: one thin path fades
before a tiny open gate while another remains visibly reachable. Render it as
an archival notebook diagram with imperfect ink, xerox softness, paper fibers,
risograph grain, sparse registration marks, and slight misregistration. Add
only tiny microtext and the short phrase “WHAT REMAINS REACHABLE?” Use saturated
cobalt-blue risograph ink as the single chromatic anchor; keep everything else
subdued charcoal and warm paper. Make it a flat scanned-paper editorial image,
not a chart, data visualization, model diagram, commercial poster, logo, or 3D
scene.
```

